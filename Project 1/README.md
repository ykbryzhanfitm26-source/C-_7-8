# Відомості що до репозиторію
## Короткий опис
Ця репозиторія містить код та файли, пов'язані з лабораторною роботою №7-8. Мета цієї роботи полягає у вивченні та практичному застосуванні Репозиторії для зберігання та керування кодом, а також для спільної роботи над проектами.
## Структура репозиторію
* Project 1 - Основна папка проекту, що містить код та файли лабораторної роботи.
* README.md - Файл з описом репозиторію та інструкціями щодо його використання.
* .gitignore - Файл, що визначає, які файли та папки слід ігнорувати при відстеженні змін у репозиторії.
## Переваги репозиторію
* Зручне зберігання та керування кодов. Використання репозиторію дозволяє зберігати код у централізованому місці, що полегшує його організацію та доступність.
* Можливість спільної роботи над проектами з іншими розробниками.
* Можливість відстеження змін у коді та повернення до попередніх версій при необхідності.
* Зручне пересилання та обмін кодом з іншими користувачами.
